Cara Pasang Config dan Setting GCAM AGC

Ikuti langkah-langkah berikut untuk memasang config GCAM AGC 8.8.

Cara memasang config

Jangan lupa download config terlebih dahulu dari bagian APK di halaman utama.

  1. Buka GCAM AGC dan buka Setelan.
  2. Masuk ke Setelan, lalu cari dan buka Custom file lalu buka icon XML nya.
  3. Di bagian Configs, tekan Save untuk menyimpan XML terlebih dahulu. Nama XML bebas, lalu tekan Yes. Langkah ini membuat folder config GCAM AGC.
  4. Buka aplikasi ZArchiver, lalu masuk ke folder Download.
  5. Cari file apip.agc di folder Download. Tekan dan tahan file tersebut, lalu pilih Salin.
  6. Masuk ke Download > AGC.8.8 > configs, lalu tempel file apip.agc di folder tersebut.
  7. Kembali ke aplikasi GCAM AGC. Buka menu kamera dari ikon di pojok kiri atas, lalu pilih Load Configs.
  8. Ketuk apip.agc untuk memuat config. Setelah selesai, kamera GCAM AGC siap digunakan.

Jika config tidak muncul, pastikan file apip.agc berada di Download/AGC.8.8/configs dan sesuai dengan versi GCAM AGC yang digunakan.
